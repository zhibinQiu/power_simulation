# 数字孪生 · 流程编排可编辑方案（V1 · 待确认）

> 本文档为方案稿，列出全部操作细节与设计取舍，供确认后进入实现。
> 当前已具备：三栏工业风界面、3D 仿真孪生、左/右栏联动、3D 点击聚焦、设备历史/实时数据。
> 本文在现有架构上扩展"可编辑流程编排"能力。

## 0. 我对需求的理解（对齐用，如有偏差请指出）

1. **编辑入口**：中央数字孪生提供"编辑"按钮，点击进入可编辑态；再次点击"完成"退出并保存方案、刷新 3D 仿真视图。
2. **编排形态（暂定卡片/节点）**：用"节点图"做编排最契合你的诉求（非线性、多输入、多输出、反馈、并行），每个工艺是一个节点卡片，左侧为输入口、右侧为输出口。
3. **端口可编辑**：每个工艺的"输入种类"和"输出种类"都可编辑（增删端口、改物料类型），因此既支持线性，也支持反馈与并行。
4. **拖拽创建**：从左栏把"工艺流程 / 设备 / 原料"拖入中央画布进行编排。
5. **左栏新增"原料"**：可查看原料与中间产物（含单位、碳因子），编排时可指定某物料作为某端口的输入或输出。
6. **右栏显示配置**：编辑态下，右侧属性面板显示——工艺流程配置参数、原料配比、绑定可调设备设定、碳/能耗预估。
7. **优化策略落点**：工艺流程优化（节点/连线）、各工艺原料配比、可调设备设定，三类都要落到可编辑项上。
8. **设备分两类**：计量设备（监测、只读）+ 可调设备（设定、可控），都需要。典型可调设备：鼓风机、皮带机等（按钢铁行业拓展）。

## 2. 数据模型（决定可扩展性的核心）

```
Material（物料/原料/产物）
  id, name, category[原料|中间产物|能源|副产品],
  unit, carbonFactor(工程估算, 可替换), color, note

Port（端口）
  id, nodeId, dir[in|out], materialType(Material.id),
  flow(流量/配比, 可空), role[主物料|能源|副产]

ProcessNode（工艺节点）
  id, templateId(工艺模板), name, kind[长流程|短流程|公用],
  pos{x,y},
  inputs[Port], outputs[Port],
  params{...按模板不同: 温度/停留时间/作业率/收得率...},
  recipe[ {materialType, ratio} ],   // 原料配比
  deviceBindings[ {deviceNodeId, setpoint} ],
  estimate{ carbon, energy, yield }   // 实时计算

DeviceNode（设备节点）
  id, deviceType(计量|可调), name, unit,
  readOnly(计量=true),
  setpoint(可调设备设定值), range{min,max},
  bindingProcessId(可绑定到某工艺),
  telemetry(历史/实时, 沿用现有 ring buffer)

Connection（连线）
  id, fromNode, fromPort, toNode, toPort,
  materialType, isFeedback(反馈弧标记)

FlowScheme（工厂方案）
  id, name, nodes[], connections[], devices[],
  baselineCarbon, baselineEnergy

Strategy（优化策略）
  id, name, baseSchemeId,
  changes[ {type: 改参数/改配比/改设备设定/增删节点/增删边}, patch ],
  result{ carbonDelta, costDelta }
```

> 端口 `materialType` 引用 `Material` 库，因此"输入/输出种类可编辑"= 改端口的 `materialType` 或增删端口。

## 3. 左栏改造

现有 Tab：设备 / 工艺流程 / 策略。新增 **原料** Tab，并把工艺、设备按你的要求分组。

### 3.1 新增「原料」Tab
- 分组：
  - **原料**：铁矿石、焦炭、煤(喷吹)、石灰石/石灰、废钢、DRI/HBI、生铁、合金(锰铁/硅铁/铝)、氧气、电力、水、天然气。
  - **中间产物**：烧结矿、球团、焦炭、铁水、高炉渣、高炉煤气(BFG)、预处理铁水、钢水、钢渣、转炉煤气(LDG)、转炉尘/污泥、精炼钢水、连铸坯、钢材、氧化铁皮、蒸汽、自发电。
  - **副产品/能源流**：焦炉煤气(COG)、BFG、LDG、余热、CO₂。
- 每个条目可**查看详情**（单位、碳因子、说明），并**拖入画布**作为"原料源"节点（仅输出端口）或在端口编辑时作为可选物料类型。

### 3.2 「工艺流程」Tab 分组
- **长流程**：烧结、球团、焦化、高炉、铁水预处理、转炉(BOF)、LF 精炼、RH 精炼、连铸、轧制、煤气发电、余热回收、除尘、CCUS。
- **短流程**：电炉(EAF)、LF、RH、连铸、轧制、煤气发电、余热回收。
- 每条工艺是可拖拽模板卡，拖入画布即生成带"典型输入/输出端口"的节点（端口仍可改）。

### 3.3 「设备」Tab 分组
- **计量设备**（只读监测）：皮带秤、失重秤、料斗秤、平台秤/汽车衡、气体流量计、液体流量计、电能表、成分分析仪、CEMS、红外/热电偶测温、皮带速度传感器。
- **可调设备**（可设定）：鼓风机、引风机、皮带机/输送机、给料机(圆盘/振动/螺旋)、泵、调节阀、燃烧器、喷吹系统(煤粉/氧气/石灰)、电极调节器(EAF/LF)、变频器、氧枪、冷却水泵、除尘器风机、余热锅炉。
- 拖入画布→生成设备节点；可调设备可"绑定"到某工艺节点，其设定值进入该工艺计算。

## 4. 中央编排画布（编辑核心）

### 4.1 节点卡片样式
- 工艺节点：标题（工艺名+类型色条）、左列输入口（小圆点+物料名）、右列输出口（小圆点+物料名）。
- 设备节点：标题（设备名+计量/可调标识）、可调设备显示"设定值"入口。
- 原料源节点：仅右侧一个输出口。
- 反馈连线用弧线并标注"↺ 反馈/循环"，与正向直线区分。

### 4.2 拖拽创建（从左栏）
- 拖「工艺」→ 生成工艺节点（带典型端口）。
- 拖「原料」→ 生成原料源节点（仅输出）。
- 拖「设备」→ 生成设备节点（可调设备带设定面板入口；计量设备仅监测）。

### 4.3 连线规则
- 从输出口拖到输入口建立连接。
- **多输入**：一个输入口可接收多个上游输出（汇合）。
- **多输出**：一个输出口可连多个下游输入（并行/分配）。
- **反馈**：允许连回上游节点（后→前），自动标记为 `isFeedback` 并画弧线，参与"节能减碳"抵扣计算。
- 端口类型不匹配时给予提示但允许（由用户自行定义物料语义）。

### 4.4 端口物料类型编辑（关键能力）
- 双击端口 → 弹层：选择物料类型（取自原料库 Materials）、设定该端口流量/配比。
- 可**增删端口**：每个工艺的输入/输出"种类"完全可编辑（满足"顺序不止线性、产物可回供"的诉求）。
- 端口删除前提示是否连带删除相关连线。

### 4.5 画布通用操作
- 选中节点：拖动改位置；`Delete` 删除；支持复制。
- 滚轮缩放、空白拖拽平移、网格吸附对齐。
- "自动布局"按钮：基于现有 `resetView` 思路，按拓扑层级规整排布。
- 空画布时提供"一键载入：长流程示例 / 短流程示例"按钮，自动生成完整节点图（见 §7）。

### 4.6 实时校验提示
- 孤儿节点（无输入且无来源的工艺）高亮警告。
- 反馈环检测提示（避免无限环；允许环但标注）。

## 5. 右栏属性（编辑态）

### 5.1 选中「工艺节点」面板
1. 基本：名称 / 类型(长/短/公用) / 说明。
2. **工艺流程配置参数**（按模板不同，示例）：
   - 高炉：风温、富氧率、喷煤比、焦比、作业率、利用系数。
   - 转炉：供氧强度、出钢温度、钢铁料消耗、作业率。
   - 电炉：通电功率、通电时间、电极消耗、废钢比、DRI 比。
   - 轧制：开轧温度、成材率、作业率。
3. **原料配比表**：各输入物料占比/流量，可编辑；含"优化建议"列（如提高球团比降焦比、提高废钢比降碳）。
4. **输出产物**：可编辑的物料类型/产量（与端口联动）。
5. **绑定设备**：列出该工艺挂的可调设备及其设定值，可增/改（调用 §3.3 设备）。
6. **碳排/能耗预估**：实时计算并显示（与顶栏 KPI 联动）。

### 5.2 选中「设备节点」面板
- 计量设备：监测项 + 实时读数（沿用现有历史/实时）。
- 可调设备：设定项（风量/带速/开度/功率…）+ 范围限制 + 当前值。

### 5.3 选中「连接/端口」
- 物料类型、流量、是否反馈。

### 5.4 方案汇总
- 当前方案总碳排 / 总能耗 / 总成本，置顶显示并与顶栏 KPI 联动。

## 7. 钢铁工艺库（领域知识，内置模板）

### 7.1 长流程链路（含物料/能源流与可回收点）
```
原料: 铁矿石+焦炭+石灰石 → 烧结/球团 → 高炉(铁水+BFG+渣)
     + 焦化(焦炭+COG)
铁水 → 铁水预处理 → 转炉(钢水+LDG+钢渣+尘) → LF/RH精炼 → 连铸 → 轧制(钢材+氧化铁皮)
能源回收: BFG+LDG+COG → 煤气发电/锅炉 → 蒸汽+自发电 → 回供鼓风/电炉/泵
余热 → 发电/供热；渣/尘/污泥 → 回用(水泥/烧结配料)；CO₂ → CCUS
```

### 7.2 短流程链路
```
原料: 废钢+DRI/生铁+合金+电(绿电优先) → 电炉EAF(钢水+电炉煤气+尘) → LF/RH → 连铸 → 轧制
能源回收: 电炉煤气→回收；余热→发电；自发电抵扣外购电(绿电则近零碳)
```

### 7.3 节能减碳反馈点（在节点图里表现为反馈弧）
- 煤气(BFG/LDG/COG) → 发电 → 回供电炉/鼓风/泵（降范围2排放）。
- 余热 → 发电/供热。
- 钢渣/高炉渣 → 外售建材（产物再利用减碳）。
- 尘/污泥 → 回烧结配料（闭环减废）。
- 转炉煤气 → 钢包烘烤/混铁炉。
- 提高废钢比/DRI 替代（短流程减碳核心）。

## 9. 计算与仿真联动

- 每个工艺节点有 `compute`：输入(物料,量,碳因子) + 绑定可调设备能耗 → 输出(产物量, 直接碳排, 能耗)。
- **反馈边抵扣**：某节点输出回供前序 → 扣除外购能源需求 → 净碳下降（如自发电抵扣电网电）。
- 汇总工厂总碳/总能耗 → 顶栏 KPI + 仿真态 3D 按节点碳强度着色。
- 数值为"物料平衡 + 经验碳因子"工程估算，预留接口接真实 SCADA/EMS（仅改数据源）。

- **P5 策略保存与对比**：基线 vs 优化、碳/能耗/成本对比视图。
