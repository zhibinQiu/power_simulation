## 修复 3D 数字孪生「元素闪烁」bug（Z-fighting / 透明排序）
- 现象：孪生场景里部分元素闪烁（碳排放足迹光斑、厂房玻璃窗带等随视角忽隐忽现）。
- 根因（均在 `frontend/src/three/scene.js`）：
  1. **地面光斑与地坪共面 Z-fighting**：足迹 `foot`/`carbonRing`/`ring` 位于 y=0.06~0.08，与硬化地坪 `plat`(y=0.06) 共面 → depth 抖动。
  2. **玻璃带嵌在墙体/屋面同一平面**：`_hall` 侧窗 `z=±d/2`、锯齿采光带 `y=h+1.8`（恰为屋面顶）、office 玻璃带宽出墙体 → 与墙体深度冲突。
  3. **半透明材质未关 `depthWrite`**：连廊罩壳 shell、玻璃带默认 `depthWrite:true` → 透明物体相互排序时 popping。
  4. 选中环 `ring` 透明却默认 `depthWrite:true` 且近乎共面。
- 修复：
  - 渲染器开启 `logarithmicDepthBuffer:true`（全局深度精度兜底，near0.5/far6000 大场景下的根本解）。
  - 地面光斑抬离地坪：`foot` y=0.14、`carbonRing` y=0.15(renderOrder2)、`ring` y=0.16(renderOrder3)，三者均 `depthWrite:false`（ring 原缺失）。
  - 玻璃带改用 `depthWrite:false + polygonOffset(-2,-2)`：`_hall` 侧窗外移 `±0.3`、采光带抬到 `y=h+2.2`；office 玻璃带保留宽出但加 offset；连廊 shell 加 `depthWrite:false`。
- 验证：`node --check` 通过；受管 node `vite build` ✅（71 模块，dist 已更新）。注：本环境 `rm -rf` 被 safe-delete 钩子拦，**不要把 `rm -rf dist` 前缀到 build 命令**（vite.config 已设 `emptyOutDir:false`，直接 build 即可）。

## 第二轮：闪烁未根除 + 雾团 + 拉远出现白色大球
- **白色大球根因（已确认）**：上一轮加的 `WebGLRenderer.logarithmicDepthBuffer: true` 是元凶——本场景 skydome 是 `SphereGeometry(3200) + BackSide`，在 log-depth 下大半径 BackSide 球会被渲染成实心白球/伪影，拉远时占满视口像「白色大球」。回退后天空恢复正常渐变。无头 Chrome `?zoomout` 截图验证 ✅。
- **「仍旧闪烁」真凶**：方向光阴影未设 `normalBias`（仅 `bias=-0.0006`），阴影相机覆盖 ±1100 + mapSize 2048 偏粗，地面/屋面 shadow acne 闪烁。补 `key.shadow.normalBias = 0.04` ✅。首轮的 polygonOffset/lifted decals/depthWrite:false 保留（合面 Z-fighting 与半透明排序仍靠它们）。
- **雾团**：`scene.fog = null` + 删除两处烟囱羽流 `plume = _makeParticles(34, 0xcfd6da, ...)`（animate 已有 `if (g.plume)` 守卫，安全）。
- **结论/教训**：本项目场景不要开 `logarithmicDepthBuffer`（相机 near0.5/far6000 范围下反而引入新伪影），阴影 flick fix 优先用 `normalBias` + 足够 mapSize，而非 log-depth。
- 验证：构建 76 模块 ✅；headless `?zoomout` 截图天空正常无白球、无烟雾、零 JS 报错；诊断代码已移除，最终构建 `index-2p_KuMAz.js`。

## 巡逻路径防穿模（scene.js _startPatrol）
- **穿模根因1（固定 LANE=18）**：原路径每个工序点仅 `±Z 18`，远小于厂房半深，机器人贴着/穿过厂房。改为**按每个厂房真实 AABB 外扩净距 CLEAR=12** 生成去/回程走廊。
