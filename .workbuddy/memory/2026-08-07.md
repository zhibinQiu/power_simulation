## 第二轮优化：白板海报标签 + 相机释放 + 内存/性能 + 配色收敛
- 需求：① 计量设备标签改为固定贴墙海报（不随视角旋转），背后衬白板。② 进入/退出编辑流程 + 首次加载自动重新布局设备标签。③ 允许相机完全退出厂房。④ 减少内存占用、避免卡顿、减少使用色彩。
- **3D 海报改造**（scene.js）：
  - 设备标签从 `THREE.Sprite`（始终朝向相机）改为固定平面（`THREE.Mesh`+`PlaneGeometry`）：浅色白板背板（共享 `_posterBoardGeo`/`_posterBoardMat` DoubleSide）+ 透明文字面板（每设备独立 CanvasTexture）。海报固定朝 +Z、贴在 -z 墙内表面前 0.4 单位。
  - 共享几何体/材质：所有 ~300 个设备共用 2 个 PlaneGeometry + 1 个白板 Material → 大幅降低 GPU draw call 与内存。
  - 配色收敛：计量/可调共用单一钢蓝强调色 `POSTER_ACCENT=#0860A8`（可调靠「可调」文字区分，不再用亮蓝 #1A7FD4）；画布背景透明（白板透出为底色），文字深色 #22272e/#3a4149。
  - Canvas 尺寸 360×96（比原来 240×56 更清晰但不过大），纹理关闭 mipmap、LinearFilter。
- **内存泄漏修复**：
  - 新增 `_disposeTree(obj, skipShared)` 方法：递归释放 geometry + material + **texture**（`.map.dispose()`）。
  - `_clearModel()` 改用 `_disposeTree(c, true)` — 跳过共享海报资源，释放模型独占纹理（之前每次 sceneRev++ 重建时 CanvasTexture 泄漏导致显存持续增长→卡顿）。
  - `_disposeGroup()` 改用 `_disposeTree(obj, false)` — shed 纹理（corrTex 等）也正确释放。
- **性能优化**：
  - `updateDeviceReadings()`: 仅当读数真正变化时才重绘对应标签 canvas + 上传纹理（跳过未变化的，避免每遥测 tick 全量重绘 ~300 张 canvas 的开销）。
  - `_drawLabel()`: 增加 `_lastCo2`/`_lastRole` 缓存守卫，相同 CO2 读数不重复绘制工序标签。
- **相机释放**：
  - `_clampCamera()` 从「约束在厂房内」（x/z/y 全部钳位 + target 钳位）改为仅防钻地（y≥1.5）。
  - `controls.maxDistance`: 120→700（允许完全退出厂房、自由拉远观察）。
  - `controls.minDistance`: 14→10（允许更近观察细节）。
- **编辑态自动重排**：
  - store `enterEdit()` 新增 `this.sceneRev++`（与 exitEdit 对称，进入/退出均触发 3D 场景重建→设备标签重新布局）。
  - 首页加载已有 onMounted→rebuildScene（store.ready watch 触发），覆盖"首次加载"需求。
- **配色进一步收敛**：
  - TrendChart 默认色 #1A7FD4→#0860A8。
  - sim.js _adjDevice color #1A7FD4→#0860A8。
  - scene.js adjustable ad.color #1A7FD4→#0860A8。
  - 全站现在只剩单一钢蓝强调色（无双蓝杂色）。
- 验证：npm run build 通过 ✅；headless Chrome (swiftshader) 加载 8013 → 所有 mount 标记正常、WebGL 初始化成功、控制台零 JS 报错；截图确认完整布局渲染。
