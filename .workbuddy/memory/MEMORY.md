# 项目长期记忆

## 平台定位（重要，影响所有评估）
- 本仓库 `/Users/qiuzhibin/project/simulation` 是**钢铁节能减碳数字孪生平台**：核心是**数值仿真引擎**（能流/碳流计算、工艺建模、情景对比），不是 3D 建模软件。
- 3D 数字孪生场景（Three.js）是**结果的呈现层**，只应按"清晰度"评判，不要拿 Blender/建模渲染标准去比。
- 对标物应是 MATLAB / Aspen Plus / COMSOL 等数值仿真软件；核心差距维度：数值引擎严谨性、建模灵活性、求解/分析能力、数据接入导出、结果可复现性、可视化呈现、工程工作流。
- 引擎现状：JSON 图(工序+物流+参数) + `carbon_engine.RULES` 工序类型→算法注册表；数据为模拟值，标定参考 ISO 14404 思路但非精确冶金数据（演示版）。
