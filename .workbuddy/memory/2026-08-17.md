## macOS 自带 openrsync 坑（本机 rsync 是 openrsync，非 GNU）
1. `-az` **必须带前导短横线**；写成 `az`（无 `-`）会被当成路径 → `az: (l)stat: No such file` + 退出码 23。
2. `--delete` 校验只认**独立 `-r` 标志**，不接受 `-r` 捆进 `-azr`；否则报 `rsync: --delete does not work without --recursive or --dirs`。用 `-az -r`（-r 独立）。
3. 把 rsync 放进 `if rsync ...; then :; else warn; fi`，避免非 0 退出被 `set -e` 中断后续重启步骤（也避开 `set -u` 捕获变量的未定义坑）。
4. dry-run 输出格式与 GNU rsync 不同，没有 `<` / `*deleting` 标记，不能用 grep 这些来判断变更量。
5. 远端 `backend/.venv` 是本次排查时清掉的残留（25M），容器不依赖它。
